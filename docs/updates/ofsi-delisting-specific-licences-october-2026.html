OFSI · 9 Oct · Potentially relevant

OFSI clarifies what happens to specific licences after delisting

What changed: New FAQ 205 explains that a specific licence concerning only a delisted person and no remaining sanctions is no longer needed; OFSI need not be asked to revoke it. If the person is listed again, the old licence does not reactivate. [S1]

Relevance to an IAM. A later relisting requires a new licence application. An old permission should not be treated as automatically revived.

Application to the IAM

  • For a delisting, determine whether the specific licence concerned only that person and whether any other relevant sanctions remain; retain the actual delisting record. [S1, FAQ 205]
  • If no licence is still required, OFSI says no action or contact concerning its status is needed; affected pending applications will be closed. [S1, FAQ 205]
  • For a relisting, seek a new specific licence where required and obtain the execution provider’s current position. Check other applicable regimes before any release. [S1, FAQ 205]
Evidence
Delisting/relisting record, original licence, remaining-restrictions analysis and provider response.
